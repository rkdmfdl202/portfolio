USER BEHAVIOR ANALYSIS

왜 남고, 왜 떠나는가

2023년 5월 대량 유입 사용자의 Retention 행동 분석과 반복 이용 개선 전략

TYPE Team Project
TEAM 6 Members
DATA Company Data
ROLE User Behavior · Retention Analysis

PROJECT OVERVIEW

대량 유입 이후, 누가 남고 누가 멈췄는가?

2023년 5월 대규모 신규 유입 이후 첫 Vote 경험이 실제 반복 이용으로 이어지는지 확인하고, 초기 행동과 이후 Retention의 관계를 분석했습니다.

01 · PROBLEM

첫 Vote 진입은 높았지만 이후 Retention은 빠르게 감소

89.03% 48h Activation
68.0% W2 Retention
2.8% W8 Retention

핵심 문제를 ‘첫 Vote 경험’이 아니라 ‘첫 경험을 반복 이용으로 연결하는 과정’으로 재정의했습니다.

02 · ANALYSIS

초기 강도 × 초기 지속성으로 사용자 행동을 비교

INITIAL INTENSITY 초기 강도

첫 Valid Vote 후 24시간 미만 Vote 횟수

PERSISTENCE 초기 지속성

R1~R7 중 Valid Vote 활동일 수

RETENTION 후속 잔존

R8~R14 Valid Vote 1회 이상 여부

03 · KEY INSIGHT

초기 Vote 횟수보다 여러 날 반복한 지속성이 Retention을 더 크게 구분

83.05% 고강도 · 고지속 W2
38.93% 고강도 · 저지속 W2
+44.12%p W2 Retention 격차

W2~W8에서 초기 지속성과 이후 Vote Retention 간 통계적으로 유의한 연관성을 확인했습니다. 관찰 데이터 기반 결과이므로 인과관계로 해석하지 않았습니다.

04 · ACTION

반복 이용을 만들기 위한 단계별 개선안 제안

01

R3 Re-engagement

첫 주 참여 감소 구간에 R3 재참여 알림을 제안하고 A/B Test로 효과를 검증하도록 설계했습니다.

02

Question Experience

Question 유형별 관심·신고 반응을 분석하고 LLM 기반 개인화 질문 운영 방향을 제안했습니다.

CONCLUSION

문제는 첫 Vote 자체가 아니라,
첫 경험을 반복 이용으로 연결하는 과정이었습니다.

USER SEGMENTATION ANALYSIS

지원하지 않는 구직자는 누구인가

구직자 행동 및 공고 속성 분석을 통한 채용 지원 전환율 향상

TYPE Team Project
TEAM 4 Members
DATA Company Data
ROLE User Segmentation Analysis

PROJECT OVERVIEW

채용 지원 전환율을 높이기 위한 사용자 행동 분석

지원 퍼널, 채용 공고 속성, 구직자 행동 데이터를 분석하여 지원 전환 과정의 문제를 파악하고 전환율을 높이기 위한 개선 전략을 제안한 팀 프로젝트입니다.

MY ROLE

User Segmentation Analysis

저는 구직자의 행동 데이터를 기반으로 사용자를 세그먼트로 분류하고, 지원 전환 가능성이 높은 우선 관리 대상을 정의하는 분석을 담당했습니다.

01 · ANALYSIS

3가지 행동 지표를 기반으로 사용자를 분류

RECENCY 최근 활동

최근 로그 발생일로부터의 경과 일수

JOB VIEW 공고 탐색

채용 공고 상세 페이지 조회 횟수

APPLICATION 지원 행동

지원 완료 횟수

02 · SEGMENTATION

행동 패턴에 따라 4개의 사용자 세그먼트 정의

14%

핵심 구직자

최근 방문, 공고 조회, 지원 활동이 모두 활발한 사용자

16%

적극 탐색 구직자

최근 방문과 공고 탐색은 활발하지만 실제 지원은 적은 사용자

25%

이탈 위험 구직자

과거 탐색 활동은 있었으나 최근 방문과 지원이 감소한 사용자

43%

휴면 구직자

장기간 플랫폼 활동이 없는 사용자

03 · KEY INSIGHT

탐색 의도는 높지만 지원하지 않는 ‘적극 탐색 구직자’

2,507명 적극 탐색 구직자
60회 평균 Job View
1회 평균 Application

적극 탐색 구직자는 최근에도 플랫폼을 이용하며 평균 60회의 공고 조회 행동을 보였지만, 평균 지원 완료 횟수는 1회에 그쳤습니다.

따라서 이 그룹을 탐색 의도는 높지만 실제 지원으로 전환되지 않은 사용자 로 보고 우선 관리 대상으로 선정했습니다.

04 · ACTION

탐색 행동을 실제 지원으로 연결

01

Personalized Reminder

북마크 이후 일정 기간 지원하지 않은 사용자에게 리마인드 메시지와 맞춤 공고 추천을 제공하여 지원 행동을 유도합니다.

02

Preferred Job Exposure

원격근무·연봉 공개 등 선호도가 높은 공고를 우선 노출하여 지원 전환을 유도합니다.

MY CONTRIBUTION

담당 분석

  • Recency · Job View · Application 행동 지표 정의
  • 행동 수준별 점수 기준 설정
  • 사용자 행동 기반 4개 세그먼트 정의
  • 세그먼트별 규모 및 행동 특성 비교
  • 적극 탐색 구직자를 우선 전환 타겟으로 선정
  • 타겟 기반 지원 전환 전략 제안

CONCLUSION

많이 보는 사용자가 아니라,
많이 보지만 지원하지 않는 사용자를 찾았습니다.

CONVERSION PREDICTION ANALYSIS

무료 체험 고객은 무엇이 결제를 만드는가

무료 체험 고객의 행동을 분석하고 유료 결제 가능성을 예측해 전환 전략을 제안한 프로젝트

TYPE Team Project
TEAM 6 Members
DATA Company Data
ROLE Behavior Analysis · Modeling · Strategy

PROJECT OVERVIEW

무료 체험 방문은 늘었지만, 유료 결제 전환은 낮아졌다

무료 체험 고객의 행동·지점 특성·외부 환경과 결제 전환의 관계를 분석하고, 유료 전환 가능성이 높은 고객을 예측해 우선 관리 대상과 전환 전략을 제안했습니다.

MY ROLE

Behavioral Analysis · Conversion Modeling · Business Insight

  • 방문 횟수·재방문·체류시간 기반 행동 분석
  • Random Forest · Gradient Boosting · XGBoost 모델 비교 및 개선
  • 행동·외부·위치 변수 기반 결제 가능성 예측 모델링
  • 전체 유저 대상 3일 방문 완주 프로모션 제안
  • 고관여 미결제 고객 대상 2시간 추가 이용 혜택 제안

01 · BEHAVIOR ANALYSIS

오래 머무는 것보다 반복 방문이 결제 전환을 더 뚜렷하게 구분

45.05% 재방문 고객 결제율
+10.76%p 미재방문 대비 결제율 차이
39.2% 방문자 기준 결제 전환율

결제자는 미결제자보다 평균 방문일수와 방문횟수가 높았고, 단순 체류시간은 오히려 미결제자가 더 길게 나타났습니다. 이를 통해 반복 방문 행동을 핵심 전환 신호로 해석했습니다.

02 · MODELING

행동·외부·위치 변수를 단계적으로 결합해 결제 가능성 예측 모델을 개선

FINAL MODEL Gradient Boosting

여러 모델 비교 후 최종 모델 선정

F1-SCORE 0.3894

불균형 분류 성능 지표

ROC-AUC 0.6654

최종 위치 변수 추가 후 성능

기본 변수에서 시작해 사용자 행동 요약 변수, 외부 거시 변수, 노이즈 제거, 위치 변수를 순차적으로 추가하며 모델 성능을 개선했습니다.

03 · KEY INSIGHT

예측에서 끝내지 않고, 어떤 행동을 더 만들어야 하는지로 확장

행동 분석에서는 재방문이 결제 전환과 강하게 연결되었고, 모델에서도 방문·체류 관련 행동 변수가 주요 예측 신호로 나타났습니다. 이를 바탕으로 전체 고객과 고관여 고객을 나눠 서로 다른 전환 액션을 설계했습니다.

04 · ACTION 01

전체 유저 대상 3일 방문 완주 프로모션

STRATEGY

3일 방문 완주 챌린지

3일 모두 방문한 고객에게 1개월 회원권 5% 할인 쿠폰을 자동 지급하는 전략을 제안했습니다.

VALIDATION

통계·손익 검토

카이제곱 검정과 오즈비, 손익분기 시뮬레이션을 통해 잠재 효과를 점검하고 실제 인과 효과는 A/B Test로 검증하도록 설계했습니다.

05 · ACTION 02

고관여 타겟 전용 2시간 추가 이용 혜택

571명 고관여 미결제 고객
+2시간 추가 이용권 제안
p < .001 그룹 간 체류시간 차이

목적형·단시간 이용 패턴을 보이는 고관여 미결제 고객에게 2시간 추가 이용권을 제공하고, 실제 결제 전환율 상승 여부를 A/B Test로 검증하도록 제안했습니다.

CONCLUSION

행동을 분석하고 결제 가능성을 예측한 뒤,
전체 고객과 고관여 고객에 맞는 전환 액션으로 연결했습니다.

SUBWAY SAFETY ANALYSIS

열차 내 사고는 어디에서 더 많이 발생하는가

서울시 지하철 사고 데이터를 기반으로 열차 내 사고의 시간적·공간적·구조적 패턴을 분석하고 안전 개선안을 제안한 프로젝트

TYPE Team Project
TEAM 5 Members
DATA Public Data
ROLE Train Accident Analysis

PROJECT OVERVIEW

사고 건수만이 아니라, 사고가 발생한 환경의 특징을 함께 분석

서울교통공사의 최근 5년 사고 데이터에 이용객 수, 환승 여부, 승강장 구조, 역사 노후도 등의 정보를 결합해 사고 유형별 발생 패턴을 분석했습니다. 저는 이 중 열차 내 사고 분석을 담당했습니다.

MY ROLE

Train Accident Analysis

  • 열차 내 사고 분석 가설 수립
  • 출퇴근 시간대별 이용객과 사고 비중 비교
  • 열차 내 사고 다발역 및 환승역 비중 분석
  • 곡선·직선 승강장별 사고 특성 비교
  • 사고 다발역의 역사 노후도 비교
  • 혼잡·환승·승강장 구조·노후도를 결합한 복합 인사이트 도출
  • 수직 지지봉 확충 및 능동형 현가장치 개선안 제안

01 · TIME & TRANSFER

단순 이용객 수보다 출근 시간대와 환승 구조에서 위험 패턴이 뚜렷

출근 시간 열차 내 사고 비중 최고
90% 사고 상위 10개 역 중 환승역 비중
복합 거점 다수 노선이 겹치는 환승 구조

퇴근 시간대 이용객 수가 가장 많았지만 열차 내 사고 비중은 출근 시간대에서 더 높게 나타났고, 사고 상위 10개 역 중 90%가 환승역이었습니다. 이를 통해 이용객 수 자체보다 특정 시간대의 밀집과 환승 구조가 함께 나타나는 환경에 주목했습니다.

02 · PLATFORM STRUCTURE

곡선역과 직선역은 서로 다른 위험 패턴을 보였습니다

60% 사고 상위 10개 역 중 곡선 승강장
100% TOP 10 내 직선 사고역의 환승역 비중
2가지 패턴 곡선 구조 vs 환승 혼잡

사고 다발역에서는 곡선 승강장이 자주 관찰됐지만, 직선 승강장 사고역은 모두 환승역이었습니다. 따라서 곡선역은 구조적 특성, 직선역은 환승·혼잡 특성을 중심으로 서로 다른 위험 패턴을 구분해 해석했습니다.

03 · AGING INFRASTRUCTURE

노후도도 함께 나타났지만, 단일 요인으로는 설명되지 않았습니다

사고 상위권 역에는 노후 역사가 다수 포함됐지만, 비교적 신축인 역도 사고 상위권에 포함됐습니다. 이를 통해 노후도 하나보다 곡선 선형, 환승 유입 등 여러 조건이 함께 나타나는 환경을 종합적으로 볼 필요가 있다고 판단했습니다.

04 · KEY INSIGHT

열차 내 사고는 하나의 요인보다 혼잡·환승·곡선 선형·노후도가 결합된 환경에서 집중되는 패턴

관찰 데이터에서 특정 조건과 사고 발생이 함께 나타나는 패턴을 확인했으며, 이를 인과관계로 단정하지 않고 복합 위험 요인 관점에서 해석했습니다.

05 · ACTION

분석 결과를 열차 내부 안전 개선안으로 연결

01

수직 지지봉 확충

혼잡 상황과 차량 흔들림에서 승객이 신체를 지지할 수 있는 지점을 늘려 전도 위험을 줄이는 방안을 제안했습니다.
