USER BEHAVIOR ANALYSIS

왜 남고, 왜 떠나는가

2023년 5월 대량 유입 사용자의 Retention 행동 분석

TYPE Team Project
ROLE User Behavior Analysis
TOOLS Python · Pandas · MySQL · SciPy

01 · PROBLEM

빠른 첫 Vote 진입이
실제 반복 이용으로 이어지는가?

2023년 5월 약 63.6만 명의 신규 사용자가 집중적으로 유입되었습니다. 48시간 내 첫 Vote 진입률은 높았지만, 이후 Retention은 빠르게 감소했습니다.

89.03% 48h Activation
68.0% W2 Retention
24.9% W4 Retention
2.8% W8 Retention

02 · ANALYSIS

첫 Vote 이후
강도 × 지속성으로 사용자 세분화

초기 강도 첫 Vote 후 24시간 내
Vote 횟수
초기 지속성 R1~R7 중
Vote 활동일 수

두 지표를 교차해 사용자를 고강도·고지속 / 고강도·저지속 / 저강도·고지속 / 저강도·저지속 4개 유형으로 구분했습니다.

03 · KEY INSIGHT

초기 Vote 횟수보다
초기 지속성이 Retention을 더 크게 구분

고강도 · 고지속 83.05%

VS

고강도 · 저지속 38.93%

W2 Retention 차이 +44.12%p

W2~W8에서 초기 지속성과 이후 Retention 간 통계적으로 유의한 연관성을 확인 p < .05

04 · ACTION

01

R3 Re-engagement

첫 주 참여율 감소를 바탕으로 R3 중간 재참여 알림 1회를 제안하고 A/B Test를 설계했습니다.

02

Question Experience

Question 유형별 관심·신고 행동을 분석하고 LLM 기반 개인화 질문 경험 개선안을 제안했습니다.

MY ROLE

사용자 행동과 Retention을 중심으로 분석

  • 48h Activation 기준 검토
  • 초기 강도·지속성 사용자 세분화

  • 초기 지속성 × Retention 카이제곱 검정
  • R3 재참여 액션 및 A/B Test 설계
